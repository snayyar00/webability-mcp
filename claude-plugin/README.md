# WebAbility Accessibility plugin

This folder is the Claude plugin for WebAbility. It holds only the plugin manifest, the MCP server config and the icon. It connects Claude to the hosted WebAbility MCP server at `https://mcp.webability.io/mcp`.

## Install

In Claude Code:

```
/plugin install webability-accessibility --marketplace snayyar00/webability-mcp
```

## What you can do

- Scan a live page or a full user flow for WCAG 2.2 AA, ADA and Section 508 issues
- Check an HTML snippet before you ship it
- Check colour contrast and validate ARIA
- Verify a fix on one element after you change the code
- Run a full accessibility audit report (needs a free WebAbility account)

Scans and checks work with no account. A free WebAbility account unlocks full audits and visual audits.
